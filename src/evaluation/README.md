**No script exists here, and none was written for this release.**

A `grep` across every script in the original project for agreement/kappa/
inter-model-comparison logic found no matches outside third-party library
source code inside the excluded `venv/`. The manuscript's reported
VADER-vs-RoBERTa agreement statistics (raw agreement, Cohen's Kappa) and
the aggregated cross-brand tables in
`../../results/tables/Sentiment_Analysis_Tables_Charts.xlsx` and
`../../results/tables/All_9_Tables.docx` are not reproducible from any
script in this repository -- they appear to have been assembled manually
in the original project.

Per instruction, this gap is documented rather than filled with an
invented procedure. See `../../docs/REPRODUCIBILITY_LIMITATIONS.md`,
items 1 and 2, for the exact numbers involved and a verified inconsistency
between the two tables above.
